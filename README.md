# organizador de imposto de renda
O projeto da DIO propõe criar um organizador que facilite o usuário a declarar o imposto de renda.<br>
* ferramenta usada: Google planilhas;
* obs.: Algumas funções não existem no google planilhas, então foi necessário adaptar o projeto. Por exemplo não tem como colocar link em um desenho/forma, precisei usar a função de adicionar o link na cédula para conseguir navegar entre as abas.
